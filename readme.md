📺 Edition IPTV

Edition IPTV is a web-based IPTV streaming platform that allows users to browse and watch TV channels from around the world through a simple and user-friendly interface.

The project integrates publicly available IPTV channel data and fetches the available streams into the website, making it easier for users to discover and watch channels across different countries, languages, and categories.

live demo web - https://editioniptv.onrender.com

✨ Features

- 🌍 Worldwide TV Channels — Access channels from different countries and regions.
- 🗣️ Multiple Languages — Browse channels available in various languages.
- 🎬 HD / Full HD Support — Supports compatible high-quality streams.
- 🔎 Easy Channel Search — Quickly find channels using the search functionality.
- 📂 Custom IPTV Libraries — Users can use their own IPTV/M3U playlist libraries.
- 📡 Live Streaming — Watch supported live TV streams directly through the website.
- 🖥️ Web-Based Player — No separate IPTV application is required for supported streams.
- 📱 Responsive Interface — Designed to work across desktop and mobile devices.
- ⚡ Dynamic Channel Fetching — Channel information and streams are fetched dynamically.

🛠️ How It Works

Edition IPTV uses publicly available IPTV data and integrates it into the web application.

Public IPTV Source -> Fetch Channel Data -> Edition IPTV -> Channel Search & Categories -> Web Player -> Live Streaming

Users can browse the available channels and select a channel to start streaming. The platform can also support custom IPTV libraries/playlists when a user wants to use their own channel collection.

📂 Custom IPTV Libraries

Edition IPTV can be used with custom IPTV libraries as well.

Users can provide their own compatible IPTV/M3U playlist and use their personal channel collection through the platform.

Example:

Custom M3U Playlist
        ↓
   Edition IPTV -> Parse Channels -> Browse / Search -> Watch

🚀 Getting Started

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/edition-iptv.git

2. Open the project

cd edition-iptv

3. Run the website

If the project is a static HTML/CSS/JavaScript project, simply open:

index.html

in your browser.

For development, you can also use a local server such as VS Code Live Server.
